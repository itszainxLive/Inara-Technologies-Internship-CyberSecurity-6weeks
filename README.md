## 📋 About This Repository

This repository documents my journey through **Inara Technologies'** condensed 6-week Cybersecurity Engineer training program — a hands-on curriculum combining a **3-week Basic IT foundation** with a **3-week Cybersecurity specialization**. Each week's folder contains detailed notes, terminal outputs, and annotated screenshots from every practical task I completed.

> 💡 The program is designed as a self-contained on-ramp for aspiring Cybersecurity Engineers, covering everything from Linux fundamentals to incident response — with a strong emphasis on hands-on, practical learning.

## 📅 Weekly Breakdown

### 🔵 Week 1 — Linux Foundations, SSH & Hardening
> Building the command-line foundation every security engineer needs.

- 🖥️ Shell basics & file system hierarchy
- 🔐 Permissions, users, groups & `sudo`
- 📜 Text processing (`grep`, `sed`, `awk`) & shell scripting
- ⚙️ Services, processes & SSH key setup
- 💾 Storage, `cron` scheduling & SSH hardening

---

### 🔵 Week 2 — Networking, Firewalls & Packet Analysis
> Understanding how data moves — and how to secure it in transit.

- 🌐 OSI/TCP-IP models, IP addressing & subnetting
- 🔎 DNS, HTTP/HTTPS & TLS handshakes
- 🏷️ VLANs, NAT & network diagnostics
- 🧱 `iptables`, `ufw`, `firewalld` & AppArmor
- 📡 Packet analysis with Wireshark & `tcpdump`

---

### 🔵 Week 3 — Docker, Container Security & Monitoring
> Containerization concepts and hardening real workloads.

- 📦 Containers vs VMs & Docker fundamentals
- 🧩 Docker Compose, Dockerfiles & image security
- 🛡️ Linux hardening basics & CIS Benchmark awareness
- ☸️ Application & Kubernetes security basics
- 📊 Monitoring with Prometheus/Grafana + Capstone project

---

### 🔴 Week 4 — Hardening, Identity, Cryptography & PKI
> Moving into core cybersecurity theory and practice.

- 🩹 Patching & system hardening
- 🪪 Identity, access management & MFA/TOTP
- 🔑 Cryptography fundamentals (AES, RSA, hashing, HMAC)
- 📃 PKI & TLS certificate chains
- 🎯 Threat modeling with STRIDE

---

### 🔴 Week 5 — Vulnerability Management, Web Security, IDS/IPS & SIEM
> Detecting, prioritizing, and understanding real-world threats.

- 🩺 Vulnerability management (CVE, CVSS, OpenVAS reports)
- 🕸️ OWASP Top 10 & secure coding basics
- 🚧 WAFs & API security
- 🚨 IDS/IPS with Snort & Suricata
- 📈 SIEM fundamentals with Wazuh & MITRE ATT&CK

---

### 🔴 Week 6 — Incident Response, Pen Testing Awareness, Network Appliances & Cloud Security
> Bringing it all together — response, methodology, and the cloud.

- 🚑 Incident response lifecycle (NIST SP 800-61)
- 🕵️ Penetration testing concepts & methodology
- 🧯 Network security appliances (FortiGate, pfSense, OPNsense)
- ☁️ Container, Kubernetes & cloud security
- 🎓 Final reflection & career roadmap planning
